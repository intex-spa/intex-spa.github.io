# INTEX SpA — Sitio web

Página web de INTEX SpA, taller de hojalatería y fabricación de ductos de aire acondicionado en Quinta Normal, Santiago.

- `index.html`: la página completa
- `img/`: fotos del taller

Para publicarla con GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
